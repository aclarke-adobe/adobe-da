# cards-report

Custom **cards** block. Purpose: Report or analyst-asset tiles: cover image above a title and a "Read the report" CTA; whole card clickable.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Repeating rows, one per report: cell 1 = cover image; cell 2 = heading (H2) and a paragraph holding only the CTA link.

No variations.
