# quote-logo

Custom **quote** block. Purpose: Customer testimonial with company wordmark, quotation, attribution and story link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = company logo image (optional); row 2 = quotation paragraph(s); row 3 = attribution as bold paragraphs (name/title, company) plus an optional story link.
