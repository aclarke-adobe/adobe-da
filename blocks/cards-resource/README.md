# cards-resource

Custom **cards** block. Purpose: Resource tiles with type icon, type label and linked title; whole card clickable.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1 = type icon image; cell 2 = type label paragraph and a paragraph holding the linked title.
