# cards-horizontal

Custom **cards** block. Purpose: Horizontal icon + linked-title tiles that act as in-page navigation to sections further down.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Repeating rows, one per tile: cell 1 = icon image (white glyph, coloured square is styling); cell 2 = heading (H3) containing a link. Use same-page anchors such as #connect-strategy; the whole tile is clickable.

No variations.
