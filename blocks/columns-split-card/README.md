# columns-split-card

Custom **columns** block. Purpose: Single rounded card split side by side into a text panel (heading, copy, CTA) and an image panel.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row with two cells: text cell (H2, paragraph, CTA link) and image cell. Either order works. Matching the source, the image panel is shown only at 1200px and wider; narrower viewports render the text panel alone.

## Supported variations

No variations.
