# carousel-cards

Custom **carousel** block. Purpose: Customer-story card carousel: image + title + description + CTA cards, three per view on desktop, with previous/next controls.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Repeating rows, one per card: cell 1 = image (picture or a bare image URL); cell 2 = heading (H3), description paragraph and a paragraph holding the CTA link ("Read article" / "Read now").

## Supported variations

No variations.
